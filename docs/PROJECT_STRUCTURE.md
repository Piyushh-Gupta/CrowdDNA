# Project Structure

## Directories

- `crowdflow_dna/`: Core Python backend application.
- `frontend/`: React/Vite SPA (Phase 23).
- `sdk/`: Language-agnostic client SDKs (Phase 27).
- `deployment/`: Docker, Nginx, and Infrastructure as Code (Phase 24).
- `experiments/`: Output directory for generated simulation logs and plots.
- `docs/`: Centralized markdown documentation.
- `tests/`: Comprehensive Pytest suites.
- `scripts/`: Shared utility bash scripts.
- `.github/`: CI workflows, templates, and codeowners.
