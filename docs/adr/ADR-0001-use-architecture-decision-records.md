# ADR 0001: Use Architecture Decision Records

## Status
Accepted

## Context
As the project grows, historical context for major technical decisions is frequently lost in pull requests and Slack channels. 

## Decision
We will enforce the creation of Markdown-based Architecture Decision Records (ADRs) for any major architectural, security, or infrastructural pivot.

## Consequences
- Better historical preservation of the *WHY* behind engineering decisions.
- Slight overhead during the architecture design phase.
