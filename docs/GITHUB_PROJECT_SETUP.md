# GitHub Projects Bootstrap

## How to create a GitHub Projects (v2) board
1. Go to the GitHub Organization or Repository.
2. Click on the **Projects** tab.
3. Click **New project** -> **Board**.

## Recommended Custom Fields
- **Priority**: Single select (P0, P1, P2, P3)
- **Owner**: Assignee
- **Status**: Status column
- **Sprint**: Iteration field
- **Effort**: Number (Story points or hours)
- **Dependencies**: Text (Issue numbers)
- **Risk**: Single select (Low, Medium, High)
- **Module**: Single select (Backend, Frontend, ML, etc.)

## Suggested Board Views
- **Kanban**: Standard Status grouping.
- **Sprint**: Grouped by Sprint iteration.
- **By Owner**: Grouped by Assignee.
- **By Priority**: Grouped by Priority.
- **Roadmap**: Timeline view.
