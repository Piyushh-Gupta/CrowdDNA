# Contributor Checklist

## Before Coding
- [ ] Is there an open issue?
- [ ] Am I assigned to it?
- [ ] Have I pulled the latest `develop`?

## Before Commit
- [ ] Is the code clean?
- [ ] Have I removed debugging code?

## Before PR
- [ ] Does `ruff check .` pass?
- [ ] Do all tests pass?
- [ ] Have I updated documentation?

## Before Merge
- [ ] Is the CI green?
- [ ] Has the domain owner approved it?
- [ ] Is the definition of done met?

## After Merge
- [ ] Delete the feature branch.
- [ ] Close related issues if not auto-closed.
