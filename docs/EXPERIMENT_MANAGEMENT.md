# Experiment Management Subsystem

The CrowdDNA Experiment Management Subsystem provides a generalized, immutable framework for comparing, ranking, and plotting multiple machine learning experiments. It is the canonical source for the project leaderboard.

## Overview

Located at `training/experiment_management/`, this subsystem relies entirely on artifacts generated by existing ML pipelines (`training.train_model`, `training.analyze_experiment`, `training.validate_deployment`). It does **not** run models or require GPUs, making it extremely lightweight.

## Discovery Rules

The `ExperimentDiscovery` module scans `experiments/runs/` for subdirectories.
An experiment is only loaded if it passes the `ArtifactValidator`, which enforces:
1. `metadata/experiment_metadata.json` exists.
2. At least one checkpoint exists in `checkpoints/`.

*Note: Incomplete experiments can be forcibly included using the `--include-incomplete` CLI flag.*

## Ranking Strategy

Experiments are ranked by `RankingStrategy` subclasses. The default strategy (`DefaultRankingStrategy`) applies the following tie-breaking cascade:
1. **Primary**: F1 Score (Descending - higher is better)
2. **Secondary**: Accuracy (Descending - higher is better)
3. **Tertiary**: Deployment Latency (Ascending - lower is better)

Missing metrics gracefully fall back to `"N/A"` and are sorted to the bottom of their respective comparisons.

## Output Schema

Outputs are generated in `experiments/leaderboard/` and contain a strict schema version.
Available formats include:
- `leaderboard.md`: Human-readable summary for quick review.
- `leaderboard.json`: Raw hierarchical data suitable for external integration and web UIs.
- `leaderboard.csv`: Flat tabular data suitable for spreadsheet analysis.

## Extensibility

### Adding Future Metrics
Do not scatter dictionary keys across the codebase. Add new metrics centrally in `training/experiment_management/metrics.py` within the `MetricExtractor` class. The framework automatically propagates them to the data model.

### Adding New Plots
Add a new plotting function in `training/experiment_management/plotting.py` and decorate it with `@register_plot("plot_name")`. It will automatically be executed during leaderboard generation.

## CLI Usage

```bash
# Generate the full leaderboard
python -m training.compare_experiments

# Custom directories
python -m training.compare_experiments --experiments experiments/runs --output experiments/my_leaderboard

# Top 5 only
python -m training.compare_experiments --top 5

# Debugging partial runs
python -m training.compare_experiments --include-incomplete
```
