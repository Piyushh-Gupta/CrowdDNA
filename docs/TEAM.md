# CrowdDNA Team Documentation

## Team Hierarchy
- **Technical Lead:** Piyush Gupta
- **Core Contributor:** Aayushi

## Responsibilities
- **Technical Lead:** Architecture, Backend, ML, Graph Pipeline, Dataset Generation, Orchestration, API, Deployment, Security, Release Engineering, Production, Final Integration.
- **Core Contributor:** Frontend, SDK, UI Components, Dashboard, Documentation, Accessibility, API Client, Integration Tests, End-to-End Tests, CI Improvements, Developer Experience.

## Communication Workflow
1. Initial ideas must be recorded as GitHub Issues.
2. Synchronous technical discussions must result in an Architectural Decision Record (ADR) if architecture is affected.
3. Daily check-ins via async updates.

## Review Workflow
- All code requires a Pull Request (PR).
- The Technical Lead must review architectural changes, backend, ML, and API changes.
- The Core Contributor must review frontend, UI, and SDK changes.

## Escalation
- Blocked issues must be flagged immediately during daily syncs.
- The Technical Lead has the final say on all architectural disputes.

## Ownership, Merge & Release Authority
- The primary owner of a module must approve changes to that module before merging.
- **Merge Authority:** Piyush Gupta and Aayushi have merge rights, but only after required reviews pass.
- **Release Authority:** Piyush Gupta exclusively handles production releases.
