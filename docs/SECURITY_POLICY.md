# Security Policy

## Supported Versions
- N (Current Major Version): Full security and bug fixes.
- N-1 (Previous Major Version): Critical security patches only.

## Reporting Process
Do **NOT** open public GitHub issues for vulnerabilities. Report securely to `security@crowddna.example.com`.

## Severity Levels
We categorize vulnerabilities via CVSS v3.1 scoring: Critical, High, Medium, Low.

## Response SLA
- Acknowledgment: 24 hours.
- Triage: 48 hours.
- Patch (Critical): 7 days.

## CVE Handling
Upon patching, a CVE will be published alongside a security advisory. We support a 90-day embargo for unpatched vulnerabilities.
